# Jornada de Formación y Superación Docente · UVP

Sitio estático para GitHub Pages: agenda semanal, cursos especializados, oferta con filtros, cupos en vivo, inscripción, mapa del edificio Teocalli y sistema de constancias en PDF con folio verificable. `admin.html` es el panel de coordinación.

La publicación paso a paso (GitHub, Apps Script, clave del panel, códigos y pruebas) está en **[LEEME.md](LEEME.md)**.

## Vista previa local

```powershell
python -m http.server 8000
```

Abre `http://localhost:8000`. El catálogo se carga con `fetch`, por eso no funciona abriendo el archivo con doble clic.
